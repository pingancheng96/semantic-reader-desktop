# Semantic Reader 0.20.7

本地优先的英语阅读与语义词汇库。应用由 Tauri 2、React、TypeScript 和 SQLite 组成。AI 可选，阅读、查找、收录和语义库维护都可以离线使用。

## 在 macOS 运行

- **Apple Silicon 应用包**：解压交付的 macOS arm64 ZIP，双击 `Semantic Reader.app`。应用采用本地临时签名，未经过 Apple 公证。
- **从源码运行**：需要 ARM64 Node.js 22 或 24、npm、Rust 1.96 或更新版本，以及 Xcode Command Line Tools。项目使用系统 SQLite，要求 SQLite 3.35+ 并启用 FTS5。macOS 是本次构建目标。
- 检查 `node -v` 和 `rustc -V` 后，在本目录运行以下命令。首次下载依赖需要访问 npm 和 crates.io。两个锁定文件已随项目提供。

```sh
npm ci
npm start
```

运行测试使用 `npm test`。仅构建前端使用 `npm run build`。要生成本机架构的应用 ZIP，运行 `sh scripts/package-mac.sh`，产物位于 `dist/mac/`。

## 试用流程

1. 导入 [示例 Markdown](examples/Two-senses.md)。分别选中两处 `plunged`，原形都填 `plunge`，第一处解释为「急剧下降」并创建 `Sharp decline` 组，第二处解释为「跳入水中」并创建 `Entering water` 组。每次点击「确认收录」。
2. 点击阅读器里的标注查看语境解释和语义组。也可以在语义库按组名、核心表达、原形或义项搜索，然后从出现记录跳回原文。
3. 在语义库勾选义项，执行移动或拆到新组。合并操作会将当前组的全部义项和核心表达并入目标组。相同义项合并时保留目标义项的 ID，原文记录会自动指向它。若只想修正同一义项下的部分用例，先筛选该义项，再勾选出现记录并填写新的解释。
4. 可以连续撤销最近的关系调整。新收录标注或保存语义组资料会开启新的撤销边界，之前的关系调整将无法通过界面撤销。

支持 UTF-8 的 `.md`、`.markdown` 和 `.txt`，每篇最大 2 MB。Markdown 阅读器支持标题、引用、基本列表、加粗、斜体、行内代码和围栏代码块。其他 Markdown 标记按原文显示。标注需要位于同一行且对应原文中的连续片段，因此可以选中加粗词内部，但跨越隐藏 Markdown 标记的选区无法保存。标注使用 UTF-16 偏移，对 emoji 和 CRLF 原文保持定位。

## 从 URL 导入网页

在「阅读器」左栏的「从网址导入」粘贴公开 HTTP 或 HTTPS 网页的完整地址，点击「导入网页」。应用读取网页标题，优先提取文章或主内容区域，然后把正文和跳转后的来源 URL 保存到本地。导入后可离线阅读、选词标注和导出为 TXT。也可以按标题或来源 URL 查找已导入的网页。

网页导入支持服务端直接返回的 HTML 和纯文本，适合新闻、博客和在线文章。需要登录、付费订阅或完全依赖 JavaScript 加载正文的页面可能无法导入。下载上限为 5 MB，保存的正文上限为 2 MB。内网和本机地址不可导入。已有 SQLite 词汇库会自动升级，也可恢复旧版 JSON 备份。

新导入的 HTML 会尽量保留标题、段落、列表、表格、引用、图注和图片顺序，并以阅读器样式排版。应用会保存可下载的公开 PNG、JPEG、GIF、WebP 或 AVIF 图片，最多 24 张，单张最多下载 16 MB，较大图片会尝试缩小后保存，单张保存上限 4 MB，可离线查看。导入时会尝试响应式和延迟加载图片的备用地址。图注使用 12px 字号和独立底色。对缺少图注标记的网页，阅读器也会识别紧跟图片的简短说明，以及和图片位于同一个专用容器中的较长图注。网站自定义样式和交互在阅读器中采用简化呈现。之前导入的网页仍可阅读和标注，重新导入会创建带网页版式的新文档。

打开网页文章后，可用「重新下载图片」补图。应用会核对在线正文及原有图片位置，只下载缺失项，保留已有图片和标注，并显示补图数量。失败的图片位置会显示下载失败的原因。

阅读时双击已收录的词语，右栏会直接显示本地词库笔记，包括已有义项、语义组和学习提示。若该位置已经标注，则直接打开该条标注。同一个词有多个义项时会分别显示；双击查词不会调用 AI。

## 配置 AI

在「设置」里填入服务商提供的完整 OpenAI-compatible `/chat/completions` 地址和模型名，然后保存。远程地址使用 HTTPS，本机回环地址可使用 HTTP。Windows 和 macOS 都可在应用内保存 API Key。密钥保存在当前用户应用数据目录中的独立数据库中，未加密，并与完整 API 地址绑定。也支持从进程环境读取 `SEMANTIC_READER_AI_KEY`，同时必须设置与界面配置完全对应的 `SEMANTIC_READER_AI_ENDPOINT`。无密钥的本机回环服务可直接使用。

点击「请求 AI 建议」或「补充用法与相关表达」时，应用会向该地址发送选区、所在行附近的文字和最多五个本地候选组。补充提示时也会发送该标注保存的义项。候选优先来自已收录的同形表达和相同语境，随后使用 SQLite FTS5 补充。AI 返回的组 ID 必须在候选中，建议可先修改再确认收录。若响应包含用量，面板会显示该次调用的 token 数。打开文章、点击标注和调整语义组均由本地数据库完成。

设置页会显示已保存的完整地址、模型和密钥状态。保存密钥也会保存对应的地址与模型，重启后可以继续使用。原来保存在 macOS 钥匙串里的密钥需要在应用内重新输入一次。请求失败时，应用会在 HTTP 状态后显示服务商返回的错误说明（若有）。

AI 建议创建新组时，会填入可编辑的组说明和核心词与搭配。词义建议包含当前语境的词性和语境释义、用法、英文例句，以及有区别说明的近义表达、相关概念或搭配。确认收录会把学习提示随标注存到本地。点击已有标注，可补充语境词性或学习提示。已有释义和学习提示会保留。

## 安装 Wiktionary 离线词典

1. 在「设置 → Wiktionary 离线词典」可以直接一键下载并安装，页面会分别显示下载和建索引的进度。也可以从 [Kaikki 英语词典](https://kaikki.org/dictionary/English/index.html) 下载英语 JSONL，或从 [Wiktextract 原始数据](https://kaikki.org/dictionary/rawdata.html) 下载英语版 Wiktionary 的 JSONL 或压缩 JSONL.GZ。文件较大，应用包单独交付。一键下载约 3.2 GB，安装期间需要同时容纳下载文件和新索引。
2. 进入「设置 → Wiktionary 离线词典 → 安装词典文件」，选择下载的文件。应用流式读取，筛选英语条目并建立本地 SQLite 索引，安装时间视文件大小和设备而定。重新安装成功后才会替换上一版。
3. 在阅读器选词或点击原文标注，展开右栏的「音标与词典」后，会按词典词性显示英式、美式及其他有记录的读音，保留地区标签和多个变体。若某个地区没有标注，对应项会留空。词典读音以本地安装快照为准。默认在词典缺少读音且已配置 AI 时，把选区和附近语境发给配置的 AI 服务查原形，原形命中时优先显示词典。仍缺少读音或词性时，AI 结果会在独立的「AI 补充」区显示，并在确认收录时保存。尚未安装词典也可使用 AI 补充。可在词典设置中关闭。当前语境的词性仍可由 AI 建议。旧版保存的 AI 音标折叠在学习笔记里。

词典存放在数据目录的 `wiktionary.sqlite3`，可由同一份数据文件重新安装，因此单独于词汇库 JSON 备份。数据来自 [英语 Wiktionary](https://en.wiktionary.org/)，由 [Wiktextract](https://github.com/tatuylonen/wiktextract) 提取，文本许可为 [CC BY-SA 4.0](https://en.wiktionary.org/wiki/Wiktionary:CC-BY-SA)。本地索引只提取词形、词性、IPA 与标签。

## 文章管理

打开文章后，可在标题下方选择「删除文章」。确认后删除该文章、图片、原文标注及这些标注附带的学习提示。词库义项、语义组、其他文章及其标注都会保留。文章删除无法在应用内撤销，已有的语义组关系调整仍可撤销。

在语义库打开一个组后，可以点击「删除语义组」。确认后会删除该组的核心词、义项及关联的原文标注。文章正文和其他语义组会保留。此操作不可撤销，并会清除之前的语义组操作撤销记录。

在语义库左栏点击「批量选择语义组」，勾选多个组或选中当前筛选结果，再点击「删除所选」。每次最多 500 组，删除和关联数据清理在同一个事务完成。

## 按标签整理语义组

在语义库左栏点击标签进行筛选。继续点击其他标签会取交集，可按任意顺序组合。标签旁的数字表示当前结果中可以继续筛选的组数。点击已选标签可移除该条件，「无标签」显示尚未整理的组。

首次打开 0.19 时，应用会从内置的 UNESCO Thesaurus 快照安装全部 4,500 个概念，无需联网。词条以官方英文规范词为主，少量中文标签沿用上版适配。每条数据保留官方概念链接，使用范围由英文范围说明、上位主题和替代词整理得出。在「语义库 → 管理标签」可搜索和编辑；也可以选择补充上一版的古代史与书写试用标签。也可以为已有标签填写「使用范围」来补充词表，或新增标签和范围。试用包重复安装不会覆盖自定义范围。

阅读器的「请求 AI 建议」处理词义、学习提示和语义组匹配。标签可在语义组详情页手动维护，也可在手动新建组时选择。

阅读时按 ⌘F（或 Ctrl+F）打开文章搜索。Enter 跳到下一处，Shift+Enter 跳到上一处。按 Esc 或点击「关闭」收起搜索。

默认词表来自 [UNESCO 官方 RDF/XML](https://vocabularies.unesco.org/exports/thesaurus/latest/unesco-thesaurus.rdf)，获取于 2026-11-07。[CC BY-SA 3.0 IGO](https://creativecommons.org/licenses/by-sa/3.0/igo/) 适用于词表快照及其改编。应用提取了英文规范词、英文说明、上位主题和替代词，并对部分词条适配中文标签。源代码内含可复现的 RDF 转换脚本。

试用包的中文名称和范围为 Semantic Reader 编写或改编，并保留英文参考词条及链接。参考 [UNESCO Thesaurus](https://vocabularies.unesco.org/en/en)（CC BY-SA 3.0 IGO）及 [Getty AAT](https://www.getty.edu/research/tools/vocabularies/obtain/index.html)（ODC-By 1.0）。试用包是小型选编，源自 UNESCO 的改编标签按同一 CC BY-SA 3.0 IGO 许可提供。

从左栏进入「管理标签」可以改名或合并。旧名称保留为别名，之后用旧名称添加标签仍会归到正式标签。合并标签会清除已有的语义组关系撤销记录。语义组合并会合并标签，撤销组关系调整时会还原原来的标签归属。

已有语义组升级后显示在「无标签」中，可按需补齐。JSON 备份包含标签和别名，新版仍可恢复旧版备份。

## 数据与备份

macOS 默认库位于 `~/Library/Application Support/local.semanticreader.desktop/library.sqlite3`。可用 `SEMANTIC_READER_DATA_DIR` 指定独立的词汇库目录，例如启动一个空库：

```sh
SEMANTIC_READER_DATA_DIR="$PWD/demo-library" npm start
```

「设置 → 数据导出」可导出当前原文和完整词汇库 JSON。JSON 包含文档、语义组、核心词、表达、义项与出现记录。用「从 JSON 恢复到空词汇库」导入，应用会检查外键、标注偏移和重叠。恢复在事务中执行，遇到无效记录会整体回滚。JSON 恢复上限 64 MB，导出不包含密钥、偏好或撤销历史。

数据库以稳定 UUID 连接原文位置、义项和语义组。阅读器打开文档时用数据库关联生成链接，原文按导入内容存储。合并、拆分、移动和重新分类都使用事务。

## 验证范围

自动测试覆盖网页正文提取、编码、网址限制、旧版数据库升级、Unicode 和 Markdown 锚点、同形异义、重新打开数据库、FTS5 搜索、关系调整及撤销、失败回滚、JSON 恢复、AI 地址与候选 ID 与学习提示校验、学习提示保存及恢复，以及通过模拟 Tauri 消息导入 10 篇文档、保存 100 条标注和检索 30 个语义组。真实服务的分类准确率、响应兼容性和实际成本需要使用配置的模型另行测量。

## 构建 Windows x64 安装程序

在 Windows x64 安装 Node.js、Rust MSVC 工具链和 Visual Studio Build Tools（勾选「使用 C++ 的桌面开发」），然后在项目根目录运行：

```powershell
rustup target add x86_64-pc-windows-msvc
powershell -ExecutionPolicy Bypass -File scripts/package-windows.ps1
```

打包过程需要联网。生成的 `*-setup.exe` 位于 `src-tauri/target/windows-package/x86_64-pc-windows-msvc/release/bundle/nsis/`，安装程序包含 WebView2 离线安装组件。SQLite 静态链接并启用 FTS5。Windows 和 macOS 均可在应用设置中直接保存密钥。
